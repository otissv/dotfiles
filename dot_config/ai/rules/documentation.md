## Writing Style

- Write documentation in detailed paragraphs rather than bullet lists
- Cover: architecture decisions, security considerations, performance optimizations, integration patterns, error handling strategies

## Inline Documentation

- Document complex logic with comments; write proper JSDoc for public APIs
- Document configuration options, known limitations, and breaking changes
- Follow proper versioning and maintain a changelog
